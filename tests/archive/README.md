# Arşiv regresyonları

Bu dizindeki dosyalar eski denetim turlarının geriye dönük sözleşmelerini korur.
Kalıcı Python test komutu depo kökündeki `test_smoke.py` dosyasıdır; smoke paketi
bu arşiv süitlerini de sentetik/geçici state ile sırayla çalıştırır.

Yeni kalıcı regresyonlar önce `test_smoke.py` içine eklenmelidir. Bu dizinde yeni
rapor adına göre test paketi açılmamalıdır.
