# Yardımcı araçlar

Whisper Live'ın güncel kaynak sürümünü açmak için proje kökündeki
`başlat.bat` dosyasını kullan.

Bu klasördeki dosyalar normal kullanım için gerekli değildir:

- `başlat-exe.bat`: Daha önce oluşturulmuş taşınabilir EXE'yi açar.
- `başlat-release.bat`: EXE klasörüne kopyalanabilen taşınabilir başlatıcıdır.
- `calistir.bat`: Electron olmadan Python backend'ini çalıştırır.
- `transkribe.bat`: Komut satırı transkripsiyon aracını çalıştırır.

Bu dosyalar proje kökünün bir altına taşındığı için yolları yeni konuma göre
ayarlanmıştır.
