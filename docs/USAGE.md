# Usage

## Start a conversation

1. Start Whisper Pro with npm start.
2. Select microphone or Windows system audio in Settings.
3. Choose the expected spoken language or automatic detection.
4. Select translation provider and target only if incoming translation is needed.
5. Start listening and confirm the active audio status.

Live partial text may appear before silence finalizes an utterance; final text replaces it.

## Translate only when needed

Automatic incoming translation can remain disabled. Press the translation button on a specific transcript to translate only that item. User-requested translation works independently of continuous auto-translation.

## Generate a reply

Press the reply button on an incoming transcript. Suggestions may include native text, Turkish meaning, and Turkish-readable pronunciation. Pronunciation is an aid, not a phonetic guarantee.

Push-to-talk lets you speak or type a response and translate it on demand. Quick phrases provide common replies without waiting for generation.

## Speaker diarization

Optional diarization attempts to distinguish speakers. Labels are probabilistic and may merge or split people, especially with short, overlapping, noisy, or similar voices.

## Search, export, and overlay

Conversation search and text/SRT export are available. Live-session SRT timing is approximate and should be reviewed. Game mode offers a compact overlay; borderless-windowed mode may help when exclusive fullscreen blocks overlays.

Stop listening before switching devices or closing the application. See [Privacy](PRIVACY.md) for local retention details.
