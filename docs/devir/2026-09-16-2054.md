## Change, cause, and evidence

- The application exposed OpenAI as the only official reply/pronunciation provider. Claude is now a real first-class option rather than a cosmetic label.
- Added direct Anthropic Messages API support at `https://api.anthropic.com/v1/messages`, with `x-api-key` and `anthropic-version: 2023-06-01`. Connection validation uses the official read-only `GET /v1/models` endpoint.
- Added separate Anthropic response and translation credentials, models, status, request snapshots, response text extraction, retry behavior, and input/output token accounting. Anthropic keys are never sent to OpenAI/reseller endpoints and OpenAI keys are never sent to Anthropic.
- The AI provider selector lists **Claude (Anthropic)** first and **OpenAI (Official)** second. Existing OpenAI installations keep their selection; an `ANTHROPIC_API_KEY` environment configuration selects Claude on startup.
- Claude reply/pronunciation models and translation models are independent. Translation can use Claude while replies use OpenAI, or the reverse. The existing DeepL default is not silently changed, preventing an unselected external data-flow change.
- Supported active Claude choices added from the current official lifecycle documentation: Haiku 4.5, Sonnet 4.6, Sonnet 5, and Opus 5. The default Claude model is Haiku 4.5 for low-latency live use.
- Updated English README, installation, usage, privacy, architecture, troubleshooting, `.env.example`, localization strings, and the internal developer guide.

## Use

1. Open **Settings > System and AI Settings**.
2. Select **Claude (Anthropic)** under **AI provider**.
3. Enter an Anthropic API key, choose Claude reply and translation models, then save.
4. For continuous/manual transcript translation, separately choose **Claude (Anthropic)** under **Translation service** and enter its translation key. This key is stored separately from the reply key.
5. To keep OpenAI replies and use Claude only for translation, leave **AI provider** on OpenAI and select Claude only in **Translation service**.

Environment setup is also available through `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, and `ANTHROPIC_RESPONSE_MODEL` in the ignored `.env` file.
